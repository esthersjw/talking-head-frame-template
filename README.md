# 口播边框模板

将原始竖屏口播剪成「自定义边框图 + 中央口播窗口 + 大标题 + 字幕」的可编辑 ChatCut 成片。

## 适用场景

适合有一段未包装的口播视频，以及一张中间留白的边框、海报或纸张风格图片时使用。开头可选择使用内置的无手蓝色纸张边框，或上传自己的边框图。Skill 会将图片中间的留白处理为透明窗口，让口播从下方透出，同时保留纸边、贴纸等前景装饰。

## 成片流程

1. 先选择内置无手蓝色纸张边框，或上传自己的边框图；自定义图会先进行窗口与前景遮挡分析，并由用户确认绿幕范围。
2. 将口播调整为 1.1 倍速。
3. 基于文字稿删除无意义的气口、重复、口误和口癖，保留自然的语义与呼吸节奏。
4. 将边框图中央留白抠成透明窗口，放在口播画面上方，形成双视觉图层。
5. 依据窗口和装饰的安全区域放置字幕与两行以内的大标题。
6. 字幕完成字体、字号和语义断句后，按专有名词库终校人名、品牌和英文短语，避免错拼、错大小写或将一个英文短语拆开。
7. 在开头、中段和结尾检查画面叠层、字幕同步和剪辑连贯性。

## 使用方式

上传一段原始口播视频后，对 ChatCut 说：

```text
用 $talking-head-frame-template 剪这段口播，并使用默认边框。
```

也可以改为：`并使用我上传的边框图。` 默认输出 9:16 竖屏。若自定义边框图没有清晰的中央留白，或抠图会损坏关键装饰，Skill 会要求更换适合作为边框的图片或指定窗口范围。
