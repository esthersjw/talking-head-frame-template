# 参考版式与检查

此模板从一支 1080×1918 的竖屏参考成片归纳而来。实际项目应以用户自己的边框图窗口边界为准，而非逐像素复制。

## 相对布局

| 元素 | 建议位置 |
| --- | --- |
| 口播窗口 | 画面宽度约 75–85%，位于中部，以上下装饰和标题的安全空间为准 |
| 人物脸部 | 窗口的上半至中部，保证眼睛和嘴部清晰 |
| 字幕 | 窗口下缘下方的留白区；默认单行、约画面 85% 宽，Smiley Sans 白字配深色圆角底卡 |
| 大标题 | 窗口外的底部优先；长标题可明确拆为两行并默认左对齐，不安全时放顶部 |
| 边框图 | 全画面覆盖，中央窗口透明 |

## 视觉验收

1. 在任意时间点，观众都能看出人物位于边框的“里面”，而不是一张不透明图片盖住了人物。
2. 边框的手、纸张边、贴纸等前景元素应遮在口播之上。
3. 字幕不压住嘴巴，不与底部大标题重叠；标题不压住贴纸、手或窗口。
4. 窗口内的视频没有变形、黑边或突然的缩放跳动。
5. 标题文案根据当期口播生成，保持两行以内；长标题的人工换行必须在预览与导出中一致。标题与字幕均可继续调整字体、字号、颜色、描边和位置；不要复用参考视频文案。
6. 本模板的底部两行标题以“大图层等比放大”的方式获得醒目字号；若标题存在多个相邻片段，检查它们的尺寸和位置一致，避免结尾跳动。
